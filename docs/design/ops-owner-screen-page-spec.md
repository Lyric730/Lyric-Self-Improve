# 员工端 / 老板端 / 大屏页面规格

状态：v1.0
日期：2026-05-27

## 1. 员工端

路由：`miniprogram/pages/staff-desk/staff-desk`

员工端只服务前台现场操作，不展示玩法规则和奖励配置。

必须保留：

- 今日球桌。
- 开台到点时间设置。
- 前台积分核销。
- 异常比赛处理。

禁止：

- 让员工配置底分、倍率、随机奖励、段位规则。
- 让员工判断比赛是否满足最低有效时间。
- 让员工手算积分。
- 出现开发说明、演示说明、mock、模拟、占位等可见文案。

## 2. 老板端

路由：`miniprogram/pages/boss-config/boss-config`

老板端集中管理复杂配置，信息可以更密，但必须分组清楚。

必须分组：

- 玩法模板。
- 积分补给。
- 防刷分门槛。
- 大屏榜单。

第一版可以先展示当前配置和保存入口，后续接入真实表单和接口。

## 3. 电视大屏

小程序内路由：`miniprogram/pages/tv-ranking/tv-ranking`

电视浏览器静态页：`screen/yunhan-tv-ranking.html`

电视大屏只展示荣誉结果，不做操作。

必须包含：

- 门店名。
- 当前赛季。
- 前三名领奖台。
- 店内总榜。
- 赏金猎人榜。
- 门店活动 / 公告位。

禁止：

- 展示复杂玩法规则。
- 展示配置入口。
- 展示手机端底部 Tab。
- 做成普通手机页面放大版。

## 4. 权限与操作留痕

当前前端已经先接入：

- `miniprogram/utils/access-control.js`：进入员工端、老板端、小程序大屏页前做角色拦截。
- `miniprogram/utils/operation-log.js`：员工和老板的关键动作统一写入操作日志入口。

已记录的关键动作：

- 员工设置球桌开台到点时间。
- 员工核销积分。
- 员工作废异常比赛。
- 老板保存门店配置。

上线前仍然必须由服务端重复校验权限，并把操作日志写入服务端数据表。前端拦截只负责减少误触和误入，不能作为安全边界。

## 5. 上线前必须补齐

- `pages/ui-kit/ui-kit` 不能进入正式 `app.json` 页面列表，只保留在仓库里做开发验收。
- 服务端员工端权限校验。
- 服务端老板端权限校验。
- 配置保存接口。
- 球桌到点时间接口。
- 积分核销流水。
- 服务端异常比赛操作日志。
- 大屏 screenToken。
- 大屏数据自动刷新接口。
