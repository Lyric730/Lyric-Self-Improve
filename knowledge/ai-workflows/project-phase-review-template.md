# Project Phase Review Template

等级：🟡 可用

用于每个项目阶段结束时，把项目产出沉淀成可复用知识。

## 使用时机

- 跨 3 个以上文件。
- 做了 30 分钟以上。
- 涉及新工具、新流程、新项目。
- 产出未来还会复用。

## 模板

```markdown
# <项目名> 阶段复盘

日期：
阶段：
交付等级：🟢 spike / 🟡 可用 / 🔴 结实

## Ship 了啥

- 交付物：
- 调用方式：
- 放置位置：

## 学了啥

- 关键概念：
- 下次我能独立做的部分：
- 还不懂的：

## 隐忧

- 已踩坑：
- 可能踩坑：
- 升级到 prod 前要补：

## 知识沉淀

- 应该复制到 knowledge 的 SOP：
- 应该更新的索引：
- 应该归档或删除的临时文件：
```

## Codex 口令

```text
把这个项目阶段产出整理成：ship 了啥 / 学了啥 / 隐忧，并沉淀到合适位置。
```
