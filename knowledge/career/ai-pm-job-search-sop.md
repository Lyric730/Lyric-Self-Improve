# AI PM Job Search SOP

等级：🟡 可用

来源项目：[projects/AI PM/ai-pm-target-positioning.md](../../projects/AI%20PM/ai-pm-target-positioning.md)

## 目标

围绕 Agent / AI 工具 / 生产力产品方向，持续做岗位覆盖、JD 抽取、能力差距、作品集和投递决策。

## 方向边界

| 层级 | 方向 |
| --- | --- |
| 主线 | Agent / AI 工具 / 生产力产品 |
| 副线 | C 端 AI 助手 / AI 应用 |
| 暂缓 | 纯 ToB 平台、深行业 AI、纯售前方案、纯模型数据岗 |

## 标准流程

1. 公司池维护：更新目标公司和产品线。
2. 岗位覆盖：按公司官网和官方招聘页搜岗位，不用少量 JD 冒充市场全貌。
3. JD 样本抽取：只收明确要求，保留来源和可信度。
4. 高频要求统计：把 JD 要求聚类成能力项。
5. 方向收敛：更新目标岗位名、主线、副线。
6. 作品集规划：围绕 Agent / AI 工具做 1 个主作品。
7. 投递准备：简历、项目叙事、面试题和学习路线对齐。

## 质量门禁

- 官方来源优先，找不到再用搜索或聚合页。
- 岗位覆盖和 JD 样本分开写。
- 不把海外抽象岗位分类直接套到中国招聘市场。
- 不在 JD 收集阶段混入个人包装分析。
- 每次更新写清楚日期和阶段。
