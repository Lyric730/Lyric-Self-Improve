# AI 产品经理求职目标公司地图

更新日期：2026-05-26  
用途：个人学习提升 / 知识管理 / AI 产品经理求职准备  
当前阶段：公司池 v1，下一阶段再逐家公司抓官网公开岗位

## 使用原则

- 这不是最终投递清单，而是后续做岗位调研、能力拆解、作品集对齐的目标公司池。
- 优先级是按“小刀老师当前想转 AI 产品经理”的现实路径排的，不等于公司市值排名。
- 重点看三类岗位关键词：`AI 产品经理`、`大模型产品经理`、`Agent / 智能体产品经理`、`AIGC 产品经理`、`AI 平台产品经理`、`AI 解决方案产品经理`、`RAG / 知识库产品经理`。
- 先把北京、深圳作为主战场，同时纳入中国头部 AI 原生公司；上海、杭州、合肥公司不直接排除，因为 AI 原生公司很多不在北京/深圳。

## 优先级说明

| 优先级 | 含义 |
|---|---|
| S | 第一批必须查官网岗位，最值得投入时间研究 |
| A | 第二批重点关注，有合适 AI PM 岗位就投 |
| B | 作为补充池，适合特定方向或需要更强技术/行业背景 |
| C | 暂时只观察，不作为第一阶段主攻 |

## 下一阶段岗位抓取模板

逐家公司官网招聘页抓取时，建议记录这些字段：

| 字段 | 说明 |
|---|---|
| 公司 | 目标公司名 |
| 岗位名称 | 官网原始岗位名 |
| 城市 | 北京 / 深圳 / 上海 / 杭州 / 远程等 |
| 岗位类型 | AI 应用 / Agent / 平台 / 解决方案 / 增长 / 数据 / 安全 |
| JD 核心职责 | 只摘 3-5 条，不复制整段 |
| JD 明确要求 | 只摘 JD 里明确写出来的学历、年限、技术、行业、语言、协作等要求，不脑补 |
| 投递难度 | 低 / 中 / 中高 / 高 / 极高，按 JD 门槛排序 |
| 官网链接 | 必须是公司官网招聘页或官方飞书/北森/牛客/脉脉招聘入口 |

## 对小刀老师当前最现实的主攻方向

| 方向 | 为什么 |
|---|---|
| AI Agent 产品经理 | 国内 AI 原生公司和大厂都在做 Agent；可以用 Dify / Coze / RAG / 浏览器自动化 / 工作流做作品集 |
| AI 应用产品经理 | 最贴近招聘市场主流，不要求训练模型，重点是场景拆解、流程设计、效果评估 |
| AIGC / 内容工具产品经理 | 你已有自媒体、内容、增长学习背景；MiniMax、快手、字节、生数这类公司更相关 |
| AI 解决方案产品经理 | 入场机会多，但要小心岗位变成售前/项目经理；投之前必须拆 JD |

## 暂不作为第一主线的方向

| 方向 | 原因 |
|---|---|
| 纯模型评测 / Model Behavior | 国内岗位较少，且更偏算法/评测体系，对初转 AI PM 不友好 |
| 纯 AI Infra 平台 PM | 很有价值，但技术门槛高，适合作为第二阶段能力升级 |
| AI Safety / Trust PM | 海外大厂更成熟，国内公开岗位不稳定 |
| 智能硬件 PM | 大疆、荣耀、小米有机会，但会偏硬件/系统/供应链，和 AI PM 主线有偏差 |
