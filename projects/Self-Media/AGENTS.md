# Agent 工作规则

> 适用于本项目内所有 Agent / Codex / Claude 工作。进入项目后，先读 `README.md`，再读本文件，最后读具体产线文档。

## 最高优先级：先出方案，再执行

除非用户明确说“跳过方案”“直接执行”“不用讨论”，否则任何非纯问答任务都不能直接开始实现、改文件、生成图、跑流程或重构。

执行前必须先给出一版可审阅方案，至少包含：

1. **目标**：这次到底要解决什么问题。
2. **范围**：会动哪些文件、模块、页面或流程；哪些内容明确不动。
3. **细节构建**：页面组件、内容结构、数据流、素材来源、脚本步骤、视频节奏等关键细节要拆开说清楚。
4. **取舍理由**：为什么这样做，放弃了什么方案。
5. **交付物**：最后会产出什么文件、预览页、图片、视频或文档。
6. **验证方式**：怎么判断这次真的做好了，比如侧边预览、截图、导出文件、尺寸检查、脚本结果。

只有用户明确确认，例如“执行”“没问题”“按这个来”“就这样”，才能进入执行。

## 视觉与内容生产线任务的额外规则

- 不能凭感觉直接改版式。先说明参考对象、尺寸基准、信息层级、组件关系。
- 不能只做一次性 `daily/` 目录里的临时文件。涉及可复用生产线时，优先改 `lines/<line-name>/` 下的源头脚本、模板和文档。
- 封面、内页、视频、TTS、自动化流程都必须先拆解结构，再执行。
- 《三分钟未来》标准封面背景固定复用 `daily/2026-05-23/three-minute-future/work/cover/constructivist-cover-bg-v1.png`。默认流程不再重新生图；只有用户明确要求“重新探索封面/出新图”时，才进入封面设计方案与生图流程。
- 《三分钟未来》视频画布仍为 `1080x1920`，封面卡片仍为 `1080x1080`，内页卡片仍为 `1080x1416`。Hyperframes 合成时必须把卡片放进居中的安全 wrapper，并按 `0.92` 缩放，左右各留约 `43px`。
- 不要通过改静态 HTML/PNG 的基础尺寸来修复抖音裁切；静态图文尺寸是内容源头，平台安全区只在视频合成层处理。
- 如果出现“左侧截不上 / 底部账号被吃 / 顶部信息贴边”的问题，先检查 `lines/three-minute-future/build_hyperframes_sample.py` 的 `PLATFORM_SAFE_SCALE` 与 `.safe-frame`，再检查导出 MP4 是否仍为 `1080x1920`。
- 用户指出“不好看”“跑偏”“垃圾”时，先停下来总结问题，再出修正方案，不要继续盲改。

## 禁止事项

- 禁止一上来就写代码、生成图片、导出视频或跑完整流程。
- 禁止用模糊说法代替设计细节，比如“优化一下视觉”“增强高级感”“做得更好看”。
- 禁止未经确认就新增复杂依赖、改生产流程、调整尺寸基准或替用户选择声音、风格、内容方向。
- 禁止把旧产线的规则、口吻、视觉习惯混到新产线里，除非用户明确要求复用。

## 推荐工作顺序

1. 读 `README.md`、`AGENTS.md`、`CLAUDE.md`。
2. 读相关目录 README 和产线文档。
3. 复述用户目标，指出潜在风险或不确定点。
4. 给出方案与细节构建。
5. 等用户确认。
6. 执行。
7. 用预览、截图、导出文件或脚本结果验证。
8. 简短汇报改了什么、文件在哪里、还剩什么未做。
