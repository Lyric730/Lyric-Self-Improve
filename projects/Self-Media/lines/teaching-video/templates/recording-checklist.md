# Recording Checklist

日期：
视频标题：
录屏工具：

## 隐私

- [ ] 退出私人账号或切换演示账号
- [ ] 隐藏 API key、token、邮箱、手机号、真实姓名
- [ ] 清理浏览器书签栏
- [ ] 关闭桌面通知
- [ ] 关闭聊天软件弹窗
- [ ] 检查命令行历史和环境变量输出

## 画面

- [ ] 窗口比例确认
- [ ] 字体大小适合手机观看
- [ ] 鼠标指针可见
- [ ] 桌面背景干净
- [ ] 浏览器缩放比例合适
- [ ] 不显示无关标签页

## 素材

- [ ] 演示文件准备好
- [ ] 示例数据可公开
- [ ] 需要打开的页面已经登录
- [ ] 失败时可重新开始
- [ ] 最终验收画面能稳定复现

## 录制

- [ ] 每一步结束停 1 秒
- [ ] 鼠标移动放慢
- [ ] 口播不要边找资料边讲
- [ ] 出错时停止重录，不硬圆
- [ ] 录完立刻抽查关键片段
