## 什么时候升级成产线

满足任一条件，就不要继续只放 `topics/`：

- 同类主题准备连续做 3 篇以上。
- 需要固定模板、脚本、审核清单或视觉规则。
- 每次都要重复相同流程。

升级后应新建：

```text
lines/<new-line-name>/
```

并在 `lines/README.md` 和根 `README.md` 里登记。
