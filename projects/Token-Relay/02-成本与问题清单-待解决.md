## 优先级标准

- **P0**：开站前必须解决，否则不能上线
- **P1**：上线第一个月必须解决
- **P2**：稳态后再优化
- **PX**：长期挂着的风险，没法"解决"只能"管理"

## 🔴 紧迫问题清单（按优先级 + 时间排序）

### 开站前 must（**P0 全部解决**）

按"先后顺序"列：

```
第 1 周（决策阶段）：
  □ D1, D2  公司主体 + 法人
  □ E6-E11  合伙协议（最重要，先于一切技术工作）
  □ F1-F5   个人 / 职业隔离方案
  
第 2 周（上游 + 风控）：
  □ E1-E5   上游合作协议（带律师过一次）
  □ D3, D4  收款分离 + 开票品目
  □ C1, C2  风险准备金机制
  □ H1, H2, H3  应急方案 + 备用上游 + 资金隔离

第 3-4 周（技术 + 运营）：
  □ A1-A5   服务器 / 域名 / 上游 / 支付接通
  □ G1      第一批用户来源
```

### 上线第一个月（P1）

- A6, B1, B2, B3, B4: 监控 / 客服 / 拉新 / 退款 / 工单
- D5, D6, D7: 备案 / 数据合规 / 用户协议
- G2-G7: 运营 SOP
- H4-H7: 退出条件 + 复盘节点

### 稳态后（P2）

- A7, B5, C5, C6, C7: 长尾优化
