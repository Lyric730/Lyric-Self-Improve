# Token 中转站上游尽调清单

> 用法：拿这份清单逐项问上游
> 每个问题给出"期望答案"和"红旗信号"
> 目的：在签约 + 付款前判断对方是不是稳定源头

---

## 使用方法

1. 找时间和上游对接人**逐项过一遍**（建议一次过完，不要分多次——对方答案前后不一致是重要线索）
2. 对方答得**爽快、有数据、敢承诺、敢写合同** = 加分
3. 对方答得**含糊、绕开、"私下说"、"以后再谈"** = 减分
4. 任何一个 🔴 **红旗信号** = 立刻停下来重新评估
5. 关键问题（每节标 ⭐）必须有答案才能继续

---

## A. 上游身份 & 主体（先确认对方是谁）

### A1. ⭐ 公司主体注册在哪？能否提供工商信息？
- ✅ 期望：明确国家 + 注册号 + 可查链接 / 截图
- 🔴 红旗：拒绝提供 / "公司主体在境外不方便查" / "我们是个人接的"

### A2. 团队规模？技术 / 客服 / 运营各几人？
- ✅ 期望：能说清具体人数和分工
- 🔴 红旗：含糊"团队挺大的" / 拒绝透露

### A3. 做这个业务多久了？有什么过往案例？
- ✅ 期望：1-3 年+，能给 2-3 个下游中转站名字（你可以去问反馈）
- 🔴 红旗：刚开 3 个月 / 拒绝给参考客户

### A4. ⭐ 我们的固定对接人是谁？决策人是谁？
- ✅ 期望：明确人员 + 联系方式（不止微信）
- 🔴 红旗：只有一个微信号 / 经常换人对接

### A5. 在中国大陆是否有实体或合作伙伴？
- ✅ 期望：透明回答
- 🟡 注意：如果有，意味着国内可被追到（影响你的合规判断）

## B. 账号池来源 & 真实状态（核心：搞清茶叶哪来）

### B6. ⭐ 1000+ 账号是 ChatGPT Plus / Team / Enterprise 哪种？
- ✅ 期望：明确说明；越多 Team / Enterprise 越好（产能高、被封率低）
- 🔴 红旗："混合的不方便细说" / 全是 Plus

### B7. ⭐ 账号注册方式：自己注册 / 第三方收购？
- ✅ 期望：自己注册 + 自动化养号体系
- 🔴 红旗：从黑市买的 / 含糊 / "你不用管来源"

### B8. 信用卡 / 手机号来源？
- ✅ 期望：自有体系 / 合作虚拟卡 + 虚拟号供应商
- 🔴 红旗：盗卡 / RAT 卡 / 完全不说

### B9. access_token 怎么自动刷新？被风控时怎么解决？
- ✅ 期望：自研自动化登录 + 设备指纹模拟 + CAPTCHA 解决
- 🔴 红旗：手动刷 / "我们有办法"（不说细节）

### B10. ⭐ 过去 30 天账号被封比例？
- ✅ 期望：< 5%/月，明确数字
- 🔴 红旗：拒答 / "很少" / "几乎没有"（不可能）

### B11. 2024 年底 / 2025 OpenAI 大封号事件的应对历史？
- ✅ 期望：能说**具体事件 + 具体应对**（换 IP 段、改设备指纹、降频）
- 🔴 红旗："那时候没受影响" / 含糊

### B12. 账号池每月新增 / 衰减比例？
- ✅ 期望：5-15% 月度更替（这是健康的）
- 🔴 红旗：拒答 / "我们的池子一直稳定"（不符合反作弊环境）

### B13. ⭐ 单账号每天有效产能（token 数）？
- ✅ 期望：明确数字，能给后台截图佐证
- 🔴 红旗：含糊 / 只说"无限"

## C. 技术能力 & SLA

### C14. ⭐ 实际并发能力上限？历史峰值？
- ✅ 期望：明确数字（如：500 并发 / 5M tokens 每分钟）
- 🔴 红旗：拒答 / 含糊

### C15. 平均响应延迟（GPT-4o）？
- ✅ 期望：< 3s（首 token）/ < 30s（完整响应）
- 🔴 红旗："看情况" / 拒绝给数据

### C16. 过去 30 天 uptime？
- ✅ 期望：> 99%，能给监控截图
- 🔴 红旗：拒答 / "我们没断过"（不可能）

### C17. 支持哪些模型？
- 必问列表：GPT-4o / GPT-4 / GPT-4o-mini / GPT-3.5 / o1 / DALL-E / Vision / Embedding
- 🔴 红旗：只支持 GPT-4o 一种

### C18. ⭐ function calling / JSON mode / streaming 是否完整支持？
- **关键**：反代 token 通常**伪造 function calling**——必须现场真实测试
- ✅ 期望：明确支持 + 给测试 endpoint 让你自己测
- 🔴 红旗：含糊 / "基本支持" / 不让测试

### C19. ⭐ context window 实际可用多少？
- 官方 GPT-4o = 128k，反代往往被压缩到 8k-32k
- ✅ 期望：明确数字 + 让你测试
- 🔴 红旗："和官方一样" 但不给测试

### C20. ⭐ 长 context 输入是否被截断？
- 必测：扔一段 50k token 进去看回应
- 🔴 红旗：被截断 / 报错 / 不让测
