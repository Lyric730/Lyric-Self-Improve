# Yolox SEO 项目归档

这个目录整理的是 Yolox SEO 执行资料包：数据看板、关键词研究、Blog 内容生产、外链建设、技术 SEO audit 和可复用脚本。资料来自 Yolox SEO 项目归档，复制时按用途重新分类，未携带 `.git`、`node_modules`、构建缓存和运行日志。

## 目录怎么用

| 目录 | 用途 |
|---|---|
| `analytics/` | GSC、Bing Webmaster、GA4、UTM、Looker Studio 看板相关文档。 |
| `keyword-research/` | 关键词研究方法、两轮关键词产出、评分、pillar / cluster、blog outline 和数据文件。 |
| `blog/` | Blog 模板、brief、草稿，以及 `yolox-blog` 的文章归档和校验脚本。 |
| `backlinks/` | 外链执行 README、handoff、状态、候选表、数据库、脚本、外联材料和报告产出。 |
| `technical-seo/` | 技术 SEO audit 和待修补项。 |
| `workflows/` | 从项目材料里抽出的中文执行流程，可直接作为任务 SOP 使用。 |
| `scripts/` | SEO 相关脚本的集中副本，按关键词研究和外链建设分组。 |

## 推荐阅读顺序

1. 先读 `knowledge/growth-playbooks/seo/yolox-seo-sop.md`，了解完整执行边界。
2. 进入 `workflows/`，按当前任务选择看板、关键词、Blog、外链或技术 SEO 流程。
3. 需要原始证据和产出时，再进入对应分类目录查源文件。
4. 需要复用到别的项目时，读 `knowledge/growth-playbooks/seo/skills/practical-seo-execution/SKILL.md`，它已经去掉本地路径依赖。

## 复制取舍

保留了项目执行自产的 Markdown、CSV、JSON、SQLite 数据库、小脚本、Blog 内容和报告产出。没有复制源目录里的 Git 仓库元数据、依赖包、构建缓存、日志文件，以及外链参考资料中带版权风险的社群原文 docx、转换稿和图片素材。
