## 第一章 认知层：外链到底是什么、为什么做

### 1.1 三种叫法，其实是两条链接的两种视角

被新人最常搞混的一组术语：**外链 / 反链 / 内链 / 正向链接**。哥飞用一张图就讲清了本质：

![网站链接类型关系图](./_assets/图解内链（内部链接）、外链（外部链接）、反链（反向链接）、正向链接/img-001.png)

| 链接 | A 站视角 | B 站视角 |
|---|---|---|
| 链接 1（A 站 → B 站，跨站） | **外链** / 正向链接（指向外部域名） | **反链**（被外部指入） |
| 链接 2（A 站 → A 站，同站内） | **内链** / 正向链接 | 与 B 站无关 |

**一句话记住**：A 角度叫"外链"（outbound），B 角度叫"反链"（inbound / backlink）。"外链"和"反链"在日常对话里经常混着说，**本质是同一条链接的两种视角**——区分时只需问一句"以谁的网站为主语"。

> 来源：图解内链外链反链正向链接 [#20]

### 1.2 外链的两种用途——分清楚，否则会怀疑人生

很多新人质疑"我加了外链怎么没流量"，是因为把两类外链当成一回事。它们的目标、时效、ROI 算法完全不同：

| 类型 | 目的 | 时效 | 算 ROI 吗 |
|---|---|---|---|
| **权重外链**（90% 场景） | 提升域名权重 → 提升 SERP 排名 → 拿 SEO 自然流量 | **长期**，存活多年仍持续给权重 | ❌ 算不出来 |
| **流量外链**（广告投放等） | 直接带访问 → 注册付费 | **短期**，停投就撤 | ✅ 必须算 |

哥飞原话："这种外链可以存在很多年，长期给我们网站带来权重的提升，不会去看 ROI。"

**重要推论**：当你给别人主动发评论外链、提交目录站时，**别期望明天它就给你带来访问**。它的回报方式是 6 个月后某天某个关键词的排名涨了。

> 来源：外链到底有什么作用 [#22]

### 1.3 内页要不要加外链——哥飞的四句话原则

哥飞给"该不该给某内页加外链"做了个朴素的判断框架。

**四句话原则**：

1. 任何链接都能传递权重（不分内外）
2. 谷歌最小排名单位是页面（首页只是一个特殊页面）
3. 拿排名的前提是页面竞争力足够
4. 关键词搜索结果是个排行榜，页面之间相互竞争

**五步检查**（决定一个内页要不要外链）：

| 步 | 检查项 | 落地动作 |
|---|---|---|
| 1 | On-Page SEO 做了吗 | 内容瞄准 KW、主题聚焦，先进索引列表 |
| 2 | 页面竞争力够吗 | 链接权重 + 信息量 + UX 三件套 |
| 3 | 竞争对手强度如何 | 你能挤掉榜单上谁？挤不掉就先垫高自己 |
| 4 | 怎么垫高 | **先内链导权**（首页/频道页 → 内页），不够再加外链 |
| 5 | 时间够吗 | 持续加外链 **3-4 个月**才开始见效 |

> 来源：内页要不要加外链 [#14]

### 1.4 引用域 > 外链总数（Gemini 拆解的重磅认知）

这条认知是 35 篇里**对决策影响最大**的一条。哥飞和 Gemini Pro 3 的对话拆解出两个层次：

#### 上半段：**Referring Domains（引用域）数量** 远比 **Backlink 总数** 重要

| 链接位置 | 价值（相对） |
|---|---|
| 第 1 条来自域名 X 的链接 | 100% |
| 第 2-5 条来自同一域名 X（不同内容页） | 10-20%（仅强化相关性 / 锚文本多样性） |
| 第 N 条（同域全站页脚） | ≈ 0（被搜索引擎判为噪音） |

**类比**：选举投票。让一个人投 1000 票，每张多余票几乎没价值；分散到 1000 个人各投 1 票，价值最大。

**反直觉的实际场景**：
- 网站 A：100 个外链来自 100 个不同域名
- 网站 B：10,000 个外链全部来自同一个域名（如全站页脚）
- **结果**：网站 A 排名能力 >> 网站 B

#### 下半段：但是**同站给不同落地页加外链**时，规则变了

这是另一个反直觉点——

| 场景 | 是否值得做 | 为什么 |
|---|---|---|
| X 域名已链你的 A 页，再链 A 页 | ❌ 边际收益极低 | 信任票已投过 |
| X 域名已链 A 页，**新链 B 页**（不同 topic） | ✅ **强烈推荐** | 给 B "上下文相关性" + "精准锚文本"——A 的链给不了 |

**执行 SOP**（哥飞 + Gemini 共识）：

- 必须发**新内容**（不是在 A 的老文章里硬加 B 的链接）
- 锚文本与 A 完全错开，精准匹配 B 的核心关键词
- 新文章里只链 B，**别顺手再链 A 或首页**
- 这种叫 **Deep Link**——让链接结构看起来自然，不显得"全站只有首页有外链"

#### 重磅推论：DR 80 的"第二票" > DR 10 的"第一票"

> "即便根据'边际效应递减'，第二条链接传递的纯域名权重打折（比如只 20%），但因为基数大（DR 80 × 20% = 16），依然是一股巨大的推力，足以推动一个新页面起步。"
>
> ——Gemini Pro 3

> 来源：经验分享 外链建设要针对每个落地页独立做 [#6] / Gemini 战略讨论 [#13]

### 1.5 Tier 0 → 实操推论（先记着，后面用得上）

| 推论 | 实操含义 |
|---|---|
| **每个落地页都是独立战场** | Yolox 不能只给 yolox.ai 首页做外链，每个 agent / skill 的 detail 页要单独有外链计划 |
| **追广度** | 100 个不同域名的 100 条外链 >> 1 个域名的 10000 条 |
| **DR 高的"第 2 票"也值得拿** | 但要换 topic、换锚文本、独立内容 |
| **加外链后 3-4 个月才见效** | 不要 2 周看不到结果就放弃 |
| **内链 + 外链一起用** | 先内链导权（首页 → detail），不够再外面补 |

## 第二章 战略思维：在 2026 的 SEO 战场怎么想

### 2.1 外链只是 13%——别把它当 SEO 全部

哥飞解读 2025 谷歌算法排名因素权重（来源：2025 版谷歌算法解读）：

| 因子 | 权重 |
|---|---|
| 持续发布优质内容 | **23%** |
| TDH 元标题关键词 | 14% |
| **反向链接** | **13%** |
| 领域专业度 | 13% |
| 用户参与度 | 12% |
| 内容新鲜度 | 6% |
| 移动友好 | 5% |

**关键结论**：
- **新词 + 新站**：可以无外链拿排名（没人竞争）
- **老词 + 高 KD**：必须 = 外链 + 持续内容 + 时间
- 外链是"必要不充分"条件

哥飞的 `geometrydashlitepc.io` 案例：高 KD 老词 "geometry dash"，24 年 6 月上线、10 月才有显著流量（**4 个月耐心**）、第一名 1400+ 外链域名、3 个月内流量从十几万涨到 95 万。

> 来源：voiceisolator.io 案例 [#5] / 高 KD 老词案例 [#11]

### 2.2 抄作业方法论——最高 ROI 的元策略

**这是 35 篇里被重复最多次的核心方法。**

哥飞反复强调："**找到能拿到排名的同行网站，看看他们都有哪些外链，我们也去这些地方发外链。有手就行，甚至不需要思考。**"

#### 抄作业的逻辑铁底

- "既然他这个网站目前能拿到排名，那么就说明他的外链整体是有效的，即使个别有害，也没影响整体的效果。"
- "你要去抄那些目前还有排名的网站的外链。"

#### 抄作业 5 步 SOP

```
1. 在目标关键词搜索结果，找排名 Top 3-5 的同行
2. Ahrefs / SEMrush 看他们的外链来源（按"首次发现时间倒序"，
   看他们起步阶段是怎么搞的——最关键）
3. 把外链来源分类：
   a. 自助提交平台 → 立刻去注册 + 提交
   b. 邮件求加入的内容列表 → 找作者发邮件
   c. 作者专栏类（beebom / parade）→ 自己也开专栏写
   d. 评论区可留链 → 找冷门文章去发
4. 抄 ≠ 复制粘贴；是「分解功能 + 让 AI 做一样的」
5. 链轮挖掘：A 站的外链来源里有 B 站 → 看 B 的外链 → 看 C 的外链…
   无限循环
```

#### voiceisolator.io 实战拆解

- 只有 30 个外链域名就拿到 "voice isolator" 排名
- 哥飞按时间倒序看他的前几个外链，**全部是自助提交平台**（promoteproject.com 等）
- 推论："我们群里的朋友，应该都能够轻松给自己网站搞到 30 个外链吧"

> 来源：voiceisolator.io 案例 [#5] / 高 KD 老词案例 [#11] / 聊聊怎么发外链 [#30] / 哥飞 24.10.25 外链小课堂 [#19]

### 2.3 6 大野路子（Gemini 给哥飞总结的"实战玩家手段"）

> 哥飞在 [#13] 提问 Gemini："还有什么外链建设方面四两拨千斤的技巧，实用价值高，而且不像 Guest Post 听起来很符合主流价值观，但实际操作体验一坨屎的方法吗？"
>
> Gemini 给了 6 个野路子。

| # | 打法 | 难度 | 效果 | 核心动作 |
|---|---|---|---|---|
| 1 | **SaaS Testimonial** | ⭐ | ⭐⭐⭐⭐⭐ | 给你用的付费 SaaS 写好评 → 换 SaaS 首页 dofollow 链接 |
| 2 | **Image Reclamation**（图片钓鱼） | ⭐⭐ | ⭐⭐⭐⭐ | 做漂亮信息图 → 被盗用后要求加 source link |
| 3 | **Best X List Inclusion** | ⭐⭐ | ⭐⭐⭐ | "帮你的文章升级"——指出旧工具失效，请求加入你 |
| 4 | **过期域名 301**（核武器，灰帽） | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 买高相关高 DR 过期域名 → 301 重定向到自己站 |
| 5 | **Ego Bait**（自我中心诱饵） | ⭐⭐ | ⭐⭐⭐⭐ | 写盘点表把同行夸一遍 → 同行自传播 |
| 6 | **Broken Link Building 2.0** | ⭐⭐⭐ | ⭐⭐⭐⭐ | 用 Wayback Machine 复活死页面 → 找链了死链的站换链 |

#### 重点拆解 ① — SaaS Testimonial（最该立刻做）

**底层心理**：任何 SaaS 公司（hosting / SEO 工具 / 主题插件 / Email 等）都极度渴望"真实用户的证言"挂在首页提高转化率。

**操作 4 步**：
1. 盘点你用过的所有付费 SaaS
2. 看他们官网有没有 "Customer Stories" / "Testimonials" 页面
3. LinkedIn 找他们 marketing 负责人或客服
4. 话术（直接抄）：
   > "I'm the founder of [Site]. Your product solved [具体问题] for us. Happy to write a testimonial — feel free to use my name and link to my site."

**为什么是核武器**：
- 90% 小微 SaaS + 50% 中型 SaaS 会接受
- 给的是**首页 dofollow 链接**——这是 DR 70-90 的高权重位置，花钱都很难买到
- 不需要写长文，对方反而求你

#### 重点拆解 ② — Image Reclamation（被动外链长期资产）

1. 用 Canva / PPT 做几张精美信息图（统计图 / 流程图 / 概念图）
2. 给图加 Alt + 发在自己网站文章里，让 Google 图片能搜到
3. 每月做 Google 反向图片搜索（以图搜图）
4. 找到盗图网站，发邮件：
   > "Hey, noticed you used my chart. No need to remove it — just add a source link to my page, that'd be appreciated."

**核心**：把盗版变外链，对方理亏，加链接只需 10 秒，成功率极高。

### 2.4 链轮挖掘法（睡飞 SOP）

睡飞大佬总结的传统 SOP（来自 [#2] SEO 外链建设策略指南）：

![SEO 外链发布流程图](./_assets/SEO%20外链建设策略指南/img-001.png)

执行流程：

| 步 | 操作 |
|---|---|
| 1 | 选定竞品网站，SEMrush / Ahrefs 分析 |
| 2 | 导出竞品外链数据（CSV） |
| 3 | 筛选可发外链的网站（WordPress 占 76%、开放评论、允许超链接） |
| 4 | 排除：隐藏链接、JS 跳转、nofollow 标签页 |
| 5 | 准备相关内容 + 锚文本（30 字肯定 + 50 字补充 + 自然植入） |
| 6 | 发布 + 监测 |
| 7 | **链轮挖掘**：A 站给 B 站做了外链 → 看 B 的外链 → 看 C 的外链…无限循环 |

### 2.5 操作铁律（多篇交叉验证）

| 规则 | 数值 / 内容 |
|---|---|
| 锚文本精确匹配比例 | ≤ 60% |
| LSI 锚文本比例 | ≥ 40% |
| 单日外链增长 | ≤ 5 条 |
| 健康月增长率 | 8-15% / 月 |
| 验证目标站流量 | SimilarWeb 月均 ≥ 1k |
| 验证收录 | `site:目标域名` 看是否被 Google 收录 |

**锚文本多样化示例**（瑜伽课程网站）：
- 50% 主关键词 "在线瑜伽课程"
- 15% LSI "居家瑜伽训练"

- 15% LSI "初学者瑜伽指导"
- 10% 品牌名 / 裸 URL

## 第三章 渠道层：去哪里发外链

> Tier 2 渠道层分 3 大子类：博客评论 / 高权重平台 Profile / 社区论坛+NewsLetter。下面每个子类挑核心讲。

### 3.1 博客评论外链

#### 生态本质

- **来源**：早期博客程序（WordPress 为主）默认开放评论 + 提供"个人主页"字段
- **存量**：哥飞估算全球还有 **几十万到几百万** 这种存量博客
- **特点**：单条权重低 → **靠量取胜** + 自动化便宜
  - 哥飞实测用 Gemini 2.0 Flash 跑：143 个请求才 **6 美分**

#### 适用场景判断（**重要**）

| 站点类型 | 博客评论外链够用吗 |
|---|---|
| 小游戏站、低竞争词 | ✅ 单靠它就能上排名（圈子不卷） |
| AI 视频站、AI SaaS、AI Agent 平台 | ❌ 不够（同行都买高质量外链） |
| 高竞争站 | 🟡 **作"显得外链多"的辅助**——对手看你外链域名多会放弃跟你竞争该词 |

> ⚠️ **关键警告**（[#17] 评论区大罗 Roger）：
>
> "forum 外链注意比例，太高会 trigger demotion_signal（谷歌降权信号）。"

#### nofollow → Dofollow 骚操作（**重磅技术**，2026-04-15 验证）

> 来源：[#8]

**原理**：WordPress 核心 `wp_rel_nofollow()` 函数用的正则 `|<a (.+?)>|i` **没加 /s flag**，`.+?` 默认不匹配换行符。所以在 `href` 里塞真实 `\n`（charCode 10），整个 `<a>` 被正则跳过，nofollow 不会被加。

**做法**：评论**正文**里写：

```html
text before <a href="https://target-site.com/
">Anchor Text</a> more text
```

**实测**：A 站 38% / B 站 60% 成功率。

**5 种失败模式（选站前必读）**：

| 失败原因 | 识别方法 |
|---|---|
| wp_kses strip `<a>` 标签 | 翻已有评论是否有超链接 |
| 额外 sanitize 插件 | bypass 后链接仍是 nofollow ugc |
| hCaptcha Enterprise | 评论内容被清洗 |
| Jetpack Highlander | 评论在 cross-origin iframe |
| CleanTalk | 403 硬拦 |

**⚠️ 陷阱：rel="ugc"** — WP 5.3+ 默认加 ugc 属性，**等同 nofollow**。验证时 rel 必须为空或只有 `noopener noreferrer` 才算真成功。

**Playwright 自动化的两个坑**（极有价值，参考 Tier 5）：
- 直接 `evaluate` 设 textarea value **不触发** React/Vue onChange → 反垃圾系统识破。用 `pressSequentially(delay)` 一字一字敲。
- 提交按钮 `name="submit"` 会 shadow 掉 `form.submit()`。用 `HTMLFormElement.prototype.submit.call(form)` 绕。

> ⚠️ 作者备注："纯内部分享，不要外传，用的人越多被修正的可能性越大。" — 本地学习用，不外传。

### 4.6 whois 动态页骚操作（[#15]）⭐ 高阶

**原理**：利用别人网站的**动态生成链接的页面**（如 whois 查询、URL 重定向页），让搜索引擎收录这些页面时，**自动给你的域名加一条外链**。

**典型可利用页面**：

| 类型 | 例子 | 利用方式 |
|---|---|---|
| Whois 查询 | `qiuyumi.com/whois/?domain=yourdomain.com` | 在自己页面放这种链接，等搜索引擎收录 |
| 链接重定向 | `link.zhihu.com/?target=yourdomain.com` | 同上，且子域名权重高 |

**完整套路**：
1. 找一个高 DR 的网站，它有动态 URL 接收外部域名作参数
2. 检查这种动态页面**有没有 nofollow**
3. 在自己页面放这种链接 → 搜索引擎抓你的页面 → 顺着抓动态页 → 动态页生成你的域名链接 → backlink +1

**哥飞的实战发现**：自己的 qiuyumi.com 被坏人这样利用——发现一堆菠菜域名通过他的 whois 页面薅外链。后来加了验证（三级域名 / 尾斜杠不生成链接）止血。

**双面启示**：
- **进攻**：找 DR 90+ 站的动态接受参数页（如 link.zhihu.com），构造指向自己的链接
- **防守**：检查自己网站有没有这种"动态外链漏洞"，避免被坏人利用

**Akismet 重磅发现**：
> Akismet 主要看**邮箱信誉**和**IP 信誉**，**不看评论内容**。用品牌域名邮箱（`team@yourdomain.com`）注册过 → 邮箱被标记 → 之后所有评论被静默吞。

**Antispam Bee 重磅发现**：
> 监听 textarea 的 keydown 事件。JS 直接 `element.value=''` 不触发键盘事件 → 判定 bot → 403。
>
> **解决**：Playwright `pressSequentially` 逐字符输入，触发完整键盘事件链。

| dev.to | 高 | GitHub OAuth，文章内链接 Dofollow |
| telegra.ph | 92 | API 创建，秒做 |
| rentry.co | 中 | curl API，秒做 |

**第二类：SaaS 目录提交**（最高 ROI）

特征：有 "Submit product/tool" 入口 → 系统生成 listing 页 → "Visit website" 按钮默认 Dofollow。
- 获取成本极低（只填 1 个 URL）
- **Dofollow 率接近 100%**
- ⚠️ 2026 年大量转付费，**免费窗口正在关闭**

**第三类：论坛 Profile Website 字段**

| 论坛类型 | 字段 | 成功率 |
|---|---|---|
| phpBB | `pf_phpbb_website` | **100% Dofollow** |
| Boardhost 免费论坛 | Link URL | **无需注册，秒发** |
| Discuz | Site 字段 | 注意在 `op=info` 不是 `op=base` |

**🪦 已确认降级的平台（2026 加了 nofollow）**：
- `paragraph.com`、`hackmd.io`、`justpaste.it`、`codepen.io` 等 paste/note 类集体降级
- 规律：UGC 内容平台主动响应 Google 政策，加 `rel="ugc nofollow"`

#### 竞品外链反查的正确姿势（**最容易踩的坑**）

> **核心发现：同一个站的不同文章，评论审核策略不同。**

| 错误做法 | 正确做法 |
|---|---|
| 从 Ahrefs 拿到竞品在 example.com 有外链 → 去 example.com 随便找文章发 | 拿到**精确 URL**（具体哪篇）→ 检查竞品评论是否仍存活 → 在**同一篇文章**下发 |

**选文章的 heuristics**：
- 评论数 > 50 + 有明显 SEO 评论存活 = **站长不管这篇**
- 老文章（> 1 年）评论区更安全 = 站长不再关注
- 最近有新评论的老文章 = 评论区仍活跃且无审核

#### 前端不行就逆向后端 API（SOP）

1. `document.querySelectorAll('script')` 拉所有 inline script
2. 正则提取 `axios.post` / `fetch` 的 URL → API endpoint 清单
3. 试 base URL 前缀（`/api/` / `/api/v1/` / `/ajax/`）
4. 带 session cookie 直接 fetch 调用

**真实案例**：某 SaaS 目录站投票按钮 Vue mount 失败 → 逆向 `news.min.js` 发现 `POST /vote-post` → 直接 fetch 调 5 次 → 15 秒搞定"访问 5 个产品页面赚积分"的 20 分钟流程。

#### 关于 Nofollow 的反直觉认知

> **90%+ Dofollow 比例反而可能被判定为刷 DR，自然分布更安全。**

- Google 2019 把 nofollow 从"指令"改为"提示"，**会选择性传递权重**
- 高 DR 站的 Nofollow（GitHub DR96、Medium DR94）**品牌信号价值极高**
- 不要排斥 Nofollow，只是优先级排第二档

## 第七章 防御层：垃圾外链攻击自救

### 7.1 攻击场景识别（[#25]）

**真实案例**：新站上线 4 天后，曝光从正常势头突然暴跌至零，持续一周几乎归零。

**根因**：被人故意往你域名发了大量低质垃圾外链（黑帽 SEO "扯水"攻击）。

**排查 SOP**：

```
1. 看 Ahrefs / GSC 外链增长曲线
2. 比对：流量下跌时间点 vs 垃圾外链激增时间点
3. 高度吻合 → 100% 是被攻击了
4. 看垃圾外链占比（案例中达 50%）
```

**典型垃圾外链域名特征**：

```
weknow.website
backlink.wiki
zhanhao.online
pranksfl.lol
vickys.design
...
```

特征：**Ahrefs 域名评分基本为 0、奇怪后缀、随意单词组合**。

### 7.2 自救工具：Google Disavow Links

**入口**：[google.com/webmasters/tools/disavow-links-main](https://www.google.com/webmasters/tools/disavow-links-main)

**提交格式**（普通 txt 文件）：

```
domain:weknow.website
domain:backlink.wiki
domain:zhanhao.online
domain:pranksfl.lol
domain:vickys.design
```

### 7.3 评论区警告

| 警告 | 含义 |
|---|---|
| "目前暂不支持网域资源" | GSC "网域资源"（domain property）可能不能直接 Disavow，要用"网址前缀资源"（URL prefix property） |
| Ahrefs 显示首次发现时间 vs SEMrush 差距大 | 不同工具数据滞后程度不同 |

### 7.4 预防机制（**重要**）

| 措施 | 频率 |
|---|---|
| 看 1 次外链增长曲线（GSC + Ahrefs） | 每周 |
| 流量与外链曲线对齐看 | 每周 |
| 维护黑名单关键词（weknow / backlink / casino / loan 等） | 持续 |
| 熟悉 Disavow 提交流程 | 在被攻击前掌握 |
| GSC 优先用"网址前缀资源" | 一次性配置 |

## 第八章 决策框架与心法（综合所有 Tier）

### 8.1 外链类型价值排序

```
SaaS 目录提交 > 开发者博客文章 > 论坛 Profile > WP 评论 > 短链
            ↑                                              ↑
        最高 ROI                                     不要全靠这个
```

### 8.2 P0 → P3 决策框架

| 优先级 | 标准 | 例子 |
|---|---|---|
| **P0** | 立刻可做 + 资源 ≤ 1 周 + 高 ROI | SaaS Testimonial、cal.com、V2EX ai-tools、JS bookmarklet、交叉验证法 |
| **P1** | 中等资源（1-4 周）+ 中高 ROI | Claude Code + Playwright MCP 搭建、Image Reclamation 体系、48 个 Profile 平台 |
| **P2** | 长期资产（1-3 月）+ 长尾 ROI | NewsLetter / 播客 / Awesome List / 自研工具 |
| **P3** | 灰帽 / 高风险 | 过期域名 301 / nofollow → Dofollow 骚操作 |

### 8.3 心法十条（提炼自 35 篇）

1. **抄作业**是元策略——找 Top 3-5 同行，看他们的外链来源
2. **DR 是假指标，traffic 是真**——SQL 层硬过滤 `traffic >= 100`
3. **追广度**（不同域名数）> 追深度（同域多链）
4. **每个落地页独立做外链**——不能只盯首页
5. **3-4 个月才见效**——耐心是入场券
6. **40-50% Dofollow 自然分布**——不要追求 90%+ 反而看起来像刷
7. **rel 每次实测**——DB 标记不可信，提交后跑 JS 验证
8. **思维要"渣"一点**——价值交换，不是乞讨
9. **合情合理心法**——做某件事自然，顺便加自己也自然
10. **新手期不要急着自动化**——先亲力亲为练手感，再让 AI 写脚本

### 8.4 反模式（**这些坑别踩**）

| 反模式 | 为什么错 |
|---|---|
| 在新手期就追求全自动化 | 不亲手做过，无法把 SOP 描述清楚让 AI 写工具 |
| 在同一个域名反复发 | 边际效应极低，价值递减到 0 |
| 用品牌域名邮箱发评论 | Akismet 标记后所有评论被吞 |
| 评论正文直接放链接 | 大多数反垃圾系统第一道防线 |
| 看到 dofollow 标记就当成功 | 没验证 ugc 属性等于失败 |
| 看到 forum 外链占比 > 50% 还继续堆 | trigger demotion_signal |
| Guest Post 海投 | 2024 后基本失效（要么付费要么徒劳） |
| 跑 DR50+ 不看 traffic | 全是 PBN 链接农场 |

### 8.5 三段式收尾（ship 了啥 / 学了啥 / 隐忧）

#### Ship 了啥（如果完整执行）

- 一套基于 Claude Code + Playwright MCP 的外链生产线
- 一份按 Tier 分层的外链资源数据库（飞书 Base）
- 一份覆盖 SaaS 目录 / 开发者博客 / 论坛 Profile / WP 评论的多渠道矩阵
- 一套防御机制（Disavow 预案 + 周度监控）

#### 学了啥

- 外链 = SEO 13%，不是全部，但缺它高 KD 上不去
- 引用域 > 外链总数；但同站不同页规则反转
- 抄作业是元策略；交叉验证是乘数
- 2026 年的反垃圾系统 6 种态势；Akismet 看邮箱+IP 信誉而非内容
- 被动外链思路：列表诱饵法 + 数据资产化

#### 隐忧

- 🔑 **token 成本**：Yifei易飞用 2 个 Claude Max 才奔放，自己复刻要算账
- 🗑 **不可控的算法变更**：Google 政策 2026 仍在演进，dofollow 平台清单半年就过时
- 🐛 **未公开 API 灰帽**：Ahrefs API 脚本随时可能失效
- 💸 **付费墙正在关闭**：SaaS 目录 2026 大量转付费，免费窗口在关
- 🔑 **黑帽攻击风险**：solo-op 没专人盯曲线，被攻击不一定及时发现

| 引用域 | Referring Domain | 给你站做了外链的不同根域名数量 |
| 域权重 | DA / DR | Domain Authority / Domain Rating |
| 锚文本 | Anchor Text | 链接所在的可点击文字 |
| 精确锚文本 | Exact Match Anchor | 100% 匹配目标关键词的锚文本 |
| 部分匹配锚文本 | Partial Match Anchor | 包含目标关键词的变体 |
| LSI 关键词 | Latent Semantic Indexing | 与主关键词语义相关的词 |
| 跟随属性 | dofollow | 默认状态，传递权重 |
| 不跟随 | nofollow | `rel="nofollow"`，2019 后变"提示"而非"指令" |
| 用户生成内容 | UGC | `rel="ugc"`，等同 nofollow 的现代变体 |
| 关键词难度 | KD | Keyword Difficulty |
| 关键词增长 / 黄金比 | KGR | Keyword Golden Ratio |
| 程序化 SEO | pSEO | Programmatic SEO，用模板批量生成页面 |
| 客座博客 | Guest Post | 在别人站上发文章带链 |
| 赞助文章 | Sponsored Post | 付费发的 Guest Post，近年实际形态 |
| 链接交换 | Link Swap | 双方互换链接 |
| 链轮 | Link Wheel | 多站互链形成环状结构 |
| 被动外链 | Passive Link Building | 让别人主动给你链接的玩法 |
| 列表诱饵 | List Bait | "最好的 XXX" 类内容主动吸引收录请求 |
| 链接磁石 | Link Magnet | 同上，统计/工具类容易被引用 |
| 自我中心诱饵 | Ego Bait | 写表扬同行的文章让他自传播 |
