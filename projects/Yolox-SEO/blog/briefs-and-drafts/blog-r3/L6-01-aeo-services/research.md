## Data 3 · AEO services pricing tier（综合 2 个 source）

**Source 1**: [Digital Strategy Force · 2026-05-01](https://digitalstrategyforce.com/journal/how-much-should-an-aeo-agency-cost-in-2026/) (verified WebFetch)
**Source 2**: WebSearch consensus across 10 sources（Stackmatix / Gigawatt / SEM Nexus / RevvGrowth / etc.）

### 综合 tier（写文章用这个）

| Tier | $ range | 包含 | Source |
|---|---|---|---|
| **Starter / Commodity** | $1.5k – $5k/mo | 基础 schema + 2-3 AI platforms + quarterly content brief | WebSearch + DSF |
| **Mid-Market / Strategic** | $5k – $18k/mo | 4-6 AEO posts/mo + schema mgmt + monthly reporting + prompt testing | WebSearch + DSF |
| **Enterprise / Embedded** | $25k – $60k+/mo | 全 execution + outcomes-linked reporting + QBR | DSF |
| **Hourly consult** | $100 – $250/hr | strategy session | WebSearch |
| **Project-based** | $5k – $15k/project | one-time audit + schema deploy | WebSearch |
| **Performance-based** | $3k – $15k/mo | tied to prompt scope + engine coverage | WebSearch |

### Hidden costs（关键 trust 信号）

- **Tool licensing markup**：agencies bundle platform licenses with **30-50% undisclosed markup** (DSF)
- Setup / onboarding: 通常 $0-$5k 一次性
- Per-extra-page overage: $200-$500/page
- Citation tracking 是否包含 / 单收
- Schema-only vs full audit 差异

### 工具自身 yearly pricing（参考）

| 工具 | yearly | source |
|---|---|---|
| Siteimprove AEO Visibility | $12k/yr | DSF |
| Profound entry | $1.5k/yr | DSF |
| HubSpot AEO | $600/yr | DSF |
| Conductor AI Search | $24k/yr | DSF |

🔑 **写 H2.3 pricing 表**：合并 commodity → entry-level（$1.5-5k）、strategic → mid-market（$5-18k）、embedded → enterprise（$25k+）。**加 hidden cost 警示行**。
