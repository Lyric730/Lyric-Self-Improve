# Type 4 · Beginner's Guide 骨架（Pillar 主文用）

> **Ahrefs 参考**：[Duplicate Content: Why It Happens and How to Fix It](https://ahrefs.com/blog/duplicate-content/)（实测 3800-4200 字 / H2-H4 多层）

---

## 适用场景

- **全面教育资源，面向 SMB / non-tech / 新手**
- 主词是 silo 入口词（hub-level keyword）
- **yolox 4 个 Pillar 主文必用此 type**：L6-00-pillar-aeo / pillar-alpha / pillar-beta / pillar-gamma

❌ **不适用**：单一概念解释（用 Definition）/ 单一流程（用 Step-by-Step）/ 工具评测（用 List）

---

## 字数 + 结构指标

| 指标 | 数值 |
|---|---|
| **字数** | **3800-4200**（Ahrefs 实测，不是我之前以为的 4000-5000） |
| **H2 数** | 6-8（含 H3/H4 多级） |
| **H 最深** | **H4**（不是 H5/H6） |
| **Intro 字数** | 250-300 |
| **段落长度** | 50-150 字，短段为主 |
| **视觉密度** | 每 400-500 字 ≥1 视觉，总 8-10 个截图/图表 |
| **TL;DR section** | ❌ 不做独立 TL;DR；用 "Final thoughts" 收尾替代 |
| **FAQ section** | ✅ 必含（Pillar 必备 AEO 信号） |
| **CTA 处** | 3+ |

## Intro 公式（250-300 字，3 段）

**重点 stat → 澄清误区 → 学习点 map**

```markdown
**段 1（80-100 字，重点 stat）**：
开门见山一个数字 stat — "25-30% of the web is duplicate content"
（不要客套话）。
建立读者对话题严重性的认知。

**段 2（80-100 字，澄清误区）**：
反直觉澄清 — "But it's not a ticking time bomb"。
打破读者常见误解 / 媒体 hype / 厂商 FUD。

**段 3（80-100 字，学习点 map）**：
本文 5 个明确学习点 — 列 5 个 H2 主题 + "By the end you'll know X"。
鼓励读者 — "Easy to follow / no jargon"。
```

**示例（L6-00-pillar-aeo 改编）**：
> 47% of Google searches now show an AI Overview before any organic result
> (SparkToro 2026 Q1 update). For some queries — "best CRM" / "how to write
> a cover letter" — AI Overview takes 100%+ of the above-the-fold real estate.
> (重点 stat)
>
> But AEO is not "the death of SEO". The same content principles that win
> organic still win AI citations — with 4 specific additions that most blogs
> don't bother with. (澄清误区)
>
> In this guide, you'll learn what AEO is, why it overtakes SEO importance
> for SMB content brands in 2026, the 5 levers that drive citation rate, and
> the common mistakes that kill AEO before it starts. No jargon, no fluff.
> (学习点 map + 鼓励)

## H2 主体骨架

### 必含 H2 顺序（6-8 个）

```markdown
## What is [Topic]?  (概念定义,300-400 字)
   ### Brief history (可选)
   ### Common misunderstandings

## Why [Topic] matters now (重要性论证,400-500 字)
   ### Data and trends
   ### What's at stake if you ignore it

## How [Topic] works (机制原理,500-700 字)
   ### [Mechanism 1]
   ### [Mechanism 2]
   ### [Mechanism 3]

## [Topic]: Step-by-step (实操,600-800 字)
   ### Step 1: [Action]
   ### Step 2: [Action]
   ### ...

## Tools and resources for [Topic] (500-600 字)
   ### Free tools
   ### Paid tools (yolox 嵌入这里)

## Common mistakes to avoid (300-400 字)
   ### Mistake 1
   ### Mistake 2

## FAQ (300-400 字, 8-12 问)

## Final thoughts (150-200 字收尾)
```

### H 层级使用规则

- **H2** = 一级主题（6-8 个）
- **H3** = 子主题 / 分类（每个 H2 下 0-4 个）
- **H4** = 子主题内的解决方案 / 例子（如 "How to solve" / "Example"）
- **不用 H5/H6** — Ahrefs 实测不用

---

## 每个 H2 内部结构

```markdown
## [H2 title]

**段 1（开场 chunk-level 答案，50-80 字）**：
1 句自包含定义这个 H2 主题。

[可选：1 行 callout / blockquote 强调要点]

### H3 子主题 1
**段（80-150 字）**：
H3 内容。

### H3 子主题 2
**段（80-150 字）**：
H3 内容。
#### H4 解决方案
**段（50-80 字）**：
具体怎么做。

[视觉：截图 / 框架图 / 数据图，每 400-500 字 1 个]
```

---

## 内链密度（Pillar 必备）

| 类型 | 数量 |
|---|---|
| **silo 内链**（指向同 silo 的 cluster） | **≥5 个**（Pillar 主文是 hub） |
| **silo 外链**（其他 silo） | 1-2 个 |
| **product 链**（agents-store / 具体 agent） | 1-3 个 |
| **外链权威源** | 3-5 个 |

🔑 **Pillar 主文 = silo 的内链 hub**。每个 cluster 文章发布后，Pillar 必须回链。

---

## FAQ section（必含，8-12 问）

```markdown
## FAQ

### Q1: [常见问题 1]

[60-80 字答案]，含主词或同义词。

### Q2: [常见问题 2]

[60-80 字答案]。

...

### Q12: [常见问题 12]
```

**FAQ 问题来源**：
1. People Also Ask（PAA box）— 主词搜索结果
2. Reddit / Quora 真实问题
3. yolox 自己客户问题

**Schema**：frontmatter 加 `schema_type: FAQPage` → 前端注入 FAQ JSON-LD → Google PAA / AI Overview 抓取。

---

## Final thoughts（结尾收束）

```markdown
## Final thoughts

[100-150 字]：
- 不复述所有 H2
- 给 1-2 个"如果你只能记一件事"的 core insight
- 一个"下一步"call — 链到 silo 内 1-2 个 cluster 文章

**Next:**
→ [Cluster 1 link]
→ [Cluster 2 link]
```

## SEO + AEO 嵌入要点

| 项 | 在 Beginner's Guide 怎么落 |
|---|---|
| 主词 | title / H1 / 首段（前 100 字）/ URL / meta / "What is X" H2 |
| 副词 | 散布在 6-8 个 H2 / FAQ |
| chunk 自包含 | 每个 H2 + H3 开头 1 句自释 |
| citation 钩子 | intro Q1 stat + 每个 H2 ≥1 个 stat/quote + FAQ 内嵌 |
| FAQ Schema | ✅ 必含，AEO 杀器 |
| Article Schema | frontmatter 加 `schema_type: Article` |
| 视觉 | 8-10 个，至少 1 个表 |
| 内链 | silo 内 ≥5（Pillar 是 hub） |
