---

思源学长——面向北京交通大学三校区(海淀本部 / 威海 / 雄安)学生的 AI 学长助手,主打无商业转化压力的客观答疑、可溯源、不编造。

目录:

一、开发者背景
二、问题诊断
三、创意思路与设计哲学
四、核心功能(按用户分层与优先级设计)
五、用户用例
六、技术方案
七、应用价值与落地路径

一、开发者背景

开发者为北京交通大学威海校区在校学生,曾运营北交新生答疑小红书学长账号,对新生入学前后的真实问题、信息盲区与现有渠道弊端有一手观察;同时具备三段 AI 产品经理实习经历,能从用户分群、需求优先级、MVP scope 到测试上线全链路把握产品落地。

二、问题诊断

北交大三校区学生面临三类信息困境:

1)三校区流程、资源、地理差异大,但官方信息散落各处室、各小程序、各 PDF,新生与跨校区办事的老生缺乏统一入口,常需在十几个网页与多个咨询窗口间反复跳转;

2)"真学长"渠道(学长姐自媒体账号、新生群、QQ 群)信息源不透明,常以"答疑"为入口将新生引流至四六级课、雅思课、保研留学规划课、生活物品等付费转化,新生以"求真诚答疑"的预期撞上"软营销",信任成本高且伤害隐蔽;

3)查官网门槛高、术语多、跨处室协调复杂,新生常常"找到正确入口的时间比解决问题还久"。

三、创意思路与设计哲学

思源学长不是 AI 客服,而是 AI 学长——客服只回答标准化问题,学长会基于场景理解、用户分层、信息透明三个原则,给出"像人一样的建议"。

四条核心设计哲学:

(1)三校区平等覆盖——不做"主威海、捎带本部"的偏科,为本部、威海、雄安三个分区独立构建知识库,把"一校多区"做实而不只是口号;

(2)防蒙骗优先于功能丰富——宁可少做花哨功能,也要把"软营销识别"做到 KILLER 级别,这是新生体验中最大、最隐蔽的伤害,也是其他校园 AI 助手普遍忽视的差异化角度;

(3)工程化的"不编造"——每条回答附知识库来源,关键事实从原文摘录,无内容时拒绝编造,以工程约束兜底 LLM 幻觉;

(4)入口轻、出口重——前端用对话窗口降低使用门槛,后端用工作流 + 知识库 + 插件保证回答专业度。

四、核心功能(按用户分层与优先级设计)

产品按用户分层设计——P1 准 / 新入学新生、P2 跨校区办事老生、P3 服务问询用户——共七大功能:

P0 核心:
- 校区识别路由——首轮对话识别用户校区,后续回答自动定向;
- 三校区 RAG 问答——基于四个独立 KB 分区(共通 / 海淀 / 威海 / 雄安),答案带溯源;
- 涉敏预警——同时覆盖硬诈骗关键词(转账 / 包过 / 刷单等)与软引流话术(以答疑为入口的卖课、卖物转化),命中即警告并引导官方渠道。

P1 进阶:
- 跨校区差异查询——输出三校区对照清单;
- 入学手册定制生成——支持上传辅导员短信 / 入学通知截图作为入口,识图提取关键信息并自动补全辅导员完整资料(办公室、邮箱、微信、办公时间)、班级群入群规则与报到动线;随后多轮收集新生补充属性(专业、绿色通道、医保、银行卡、特殊需求),输出个性化 PDF 报到清单;
- 学长名片分享——H5 / 小程序卡片可在朋友圈、微信群分享;
- 入学倒计时——距开学 ≤30 天的新生自动追加"今天该做啥"。

五、用户用例

用例 1 | 新生入学前

威海校区新生小张距离报到还有 20 天,医保转移、银行卡办理、宿舍带什么……多个零散问题积压。

小张:"威海校区的医保怎么转过来?"
思源学长:"分三步:(1)原户籍地办理参保关系暂停;(2)报到时到威海校区学工处提交《医保转移申请表》;(3)报到当周完成补办登记。来源:《威海校区 2025 迎新指南》§3.2 · [官方链接]。"
小张追问:"那银行卡呢?"
思源学长:"报到现场设有威海农商行、建行办卡点,无需提前办,带身份证即可……"

价值:多个零散问题一次性解决 + 每条回答附官方来源,新生不必在多个 PDF 和咨询窗口反复跳转。

用例 2 | 跨校区办事老生

海淀本部大三李同学要去雄安做为期一个月的实验项目,首次跨校区,担心住宿、入校手续、用餐。

李同学:"我从海淀去雄安做实验,住宿和入校手续怎么办?"
思源学长:"我帮你列对照:
- 住宿:海淀本部住自有宿舍,雄安需向雄安研究院学工办申请临时床位;
- 入校:海淀本部校园卡直接刷,雄安需提前 3 天在访客系统报备;
- 食堂:海淀本部校园卡通用,雄安校园卡可用但需先在一卡通中心激活。
来源:雄安研究院《访校与临时住宿管理办法》(2024)。"

价值:把跨校区差异变成一次查询的可执行清单,直接服务赛题"01 服务一校多区建设"方向。

用例 3 | 防软营销识别(KILLER 场景)

新生群有"学长"私聊小王,推荐 6800 元"保研留学规划课程",称"内推可立减"。

小王:"群里学长推 6800 元保研留学规划课,内推减,值得买吗?"
思源学长:"⚠️ 警告:检测到 '保研' + '留学' + '内推' + '立减' 组合,符合以学长姐身份做付费课程引流的典型软营销话术。

正确路径:
- 保研政策咨询 → 学院教学秘书 / 研究生招生办;
- 留学规划咨询 → 学校国际处或学院国际事务办公室,均为免费;
- 个人付费课程不属于学校官方资源,慎选。"

价值:把信息差变现的话术拆穿,把新生引导回学校正规、免费的官方渠道。这是其他校园 AI 助手不具备的差异化能力。

用例 4 | 新生入学手册一站式(以辅导员短信识图为入口)

威海校区新生小李收到辅导员王老师发来的入学短信:含报到时间、地点、班级群二维码、辅导员手机号,但信息密集,后续怎么走、辅导员还有哪些信息可补、班级群怎么进、入学第一周该做啥,都不清楚。

小李上传短信截图:"思源学长,辅导员刚发了这个,能帮我看一下吗?"
思源学长:"已识图,提取到——辅导员王老师手机 [号码];报到时间 8 月 28 日上午 9:00;地点 威海校区图信中心大厅;班级群'2025 级计算机 1 班新生群'二维码已识别可直接扫码。

我帮你把辅导员资料补全:
- 王老师,计算机学院 2025 级辅导员,办公室 A 楼 308,办公时间周一至周五 9:00-17:00,邮箱 [邮箱],微信二维码已附下方;
- 班级群入群规则:进群后修改群昵称为'真实姓名+学号+寝室号',班委会会主动联系你;
- 报到当天动线:图信中心大厅领迎新包 → 院系报到处 → 宿舍办理入住 → 一卡通中心激活校园卡。"

随后思源学长引导小李完成五个补充属性收集(专业班级 / 是否绿色通道 / 是否需要医保转移 / 是否需要现场办银行卡 / 是否有特殊餐饮或住宿需求),自动生成 PDF《小李的威海校区报到清单》,内含行前准备清单、报到当天动线、五天内待办时间表、辅导员完整资料(电话 + 邮箱 + 办公室 + 微信二维码)、班级群入群指引、入学一周必办事项。

价值:一张辅导员短信截图为入口,识图自动提取 + 辅导员完整资料补全 + 班级群规则解读 + 报到动线指引 + 个性化入学手册一气呵成。新生不必在多张图、多个 PDF、多个咨询窗口之间反复拼凑信息,大幅降低入学信息焦虑——这是其他校园 AI 助手不具备的"图文多模态 + 一站式入学服务"能力。

六、技术方案

技术栈:扣子(Coze)平台 + 豆包 1.6 Pro。

知识库:四个独立分区(共通 / 海淀 / 威海 / 雄安),每个分区下子目录对齐(入学 / 校园生活 / 教务 / 行政 / 周边),便于跨校区对比检索。

工作流:两层——主对话路由(一次性完成校区识别 + 涉敏检测 + 意图分类)+ 入学手册多轮收集子流程。

插件:Coze 内置 OCR 插件(用于辅导员短信、入学通知、班级群二维码截图的识图与关键信息提取,作为 M5 入学手册入口)+ PDF 插件(用于入学手册导出)+ 内置数据库(存用户校区与新生属性,跨会话长期记忆)。

防蒙骗机制由三条工程原则支撑——每条回答附知识库来源、关键事实从原文摘录、知识库无内容时拒绝编造。

七、应用价值与落地路径

应用价值:服务三校区在校生与准入校新生,新生侧降低被"软营销"引流的概率与零散信息搜寻成本,老生侧降低跨校区办事成本,服务问询侧降低官网迷路成本,与赛题"01 服务一校多区建设"方向天然契合。

落地路径:5/17-5/25 三校区公开信息采集(KB v1)→ 5/26-5/31 完善 KB v2 + 等账号 → 6/1-6/15 Coze 平台搭建 Bot + Workflow + 联调 → 6/16-6/20 50 标准问题 + 5-10 真用户双轨测试 → 6/21 提交作品文档 + 演示视频 + PPT 三件套。
